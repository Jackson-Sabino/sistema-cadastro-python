# Sistema de Cadastro em Python

Projeto desenvolvido no 2º semestre de ADS no Senac.

Sistema completo feito em Python que permite:
- Cadastrar clientes
- Listar clientes
- Buscar por nome
- Excluir clientes
- Salvar os dados em arquivo

## Como rodar
Abra o arquivo do Dia 6 ou Dia 7 no Google Colab e clique em Executar.

## Tecnologias
- Python
- Lógica de Programação
- Dicionários e Listas
